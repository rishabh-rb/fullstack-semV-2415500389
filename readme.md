
# Project: Fullstack HTML Demos

This folder contains small HTML/CSS demos and layout examples used for learning and prototyping.

## Files overview

- **bento-layout.html**: Grid-based card layout using CSS Grid with large/wide/tall card variations and image placeholders.
- **dashboard-layout.html**: Minimal dashboard scaffold (sidebar/container placeholders) for building a dashboard UI.
- **div-backgorund.html**: Demo showing how to apply a background image to a single `div` (note filename typo: "backgorund").
- **grid.html**: Product grid template using CSS Grid; container is ready for product items.
- **index.html**: Navigation bar example (`Technova`) with responsive nav links and a login button.
- **my-first-webpage.html**: Empty placeholder file (no content).
- **newspaper_structure.html**: Multi-column newspaper-like layout using CSS `column-count` for article flow.
- **productcards.html**: Product cards demo with images, descriptions and `Buy Now` buttons (flexbox layout).
- **test.html**: Stylized demo page with gradient text, centered content and example image — useful for visual experiments.
- **the_TOI_newspaper.html**: More complete newspaper layout (header, grid-based news sections, ads and sample content).
- **readme.md**: This file — summaries of the files in this folder.

## How to use

- Open any `.html` file in your browser to preview the layout (double-click or `open` from terminal on macOS).
- Files are standalone examples — you can copy the markup into other projects or modify styles directly.
